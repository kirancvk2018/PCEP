# PCEP Platform — Quick Start Guide

## 🚀 Get Started in 2 Minutes

### Step 1: Open the File
- Download `pcep-index.html` from the outputs folder
- Open it in any web browser (Chrome, Firefox, Safari, etc.)
- No server needed!

### Step 2: Register as Participant
```
Click "Register" tab
├─ Full Name: John Doe (or any name)
├─ Email: john@example.com
├─ Phone: +91-XXXXXXXXXX (optional)
├─ Target Date: Pick any date
├─ Level: Beginner / Intermediate / Advanced
└─ Click "Register & Continue"
```

### Step 3: You'll See Dashboard
Shows 6 test cards:
- Section 1: Python Basics & Data Types
- Section 2: Control Flow
- Section 3: Collections & String Ops
- Section 4: Functions & Scope
- Section 5: Exception Handling
- Section 6: OOP & Modules

### Step 4: Start a Test
1. Click **"Start Test"** on any section (e.g., Section 1)
2. Read the intro description
3. Click **"Start Test"** button again
4. Begin answering 30 multiple-choice questions
5. Use "Next →" and "← Previous" to navigate

### Step 5: Watch Timer
- 25-minute countdown in top-right
- Yellow at 5 minutes left
- Red at 1 minute left
- Auto-submits when time runs out

### Step 6: Submit Test
- Answer all 30 questions (or some, if you want)
- Click **"Submit Test"** button at bottom
- Test is instantly graded

### Step 7: See Results
Shows:
- ✓ or ✗ (passed if ≥ 70%)
- Score: X/30 (e.g., 24/30)
- Percentage: XX%
- Time taken: MM:SS
- Stats: Correct, Incorrect, Percentage, Time
- **Full answer review**: See every Q with explanation

### Step 8: Back to Dashboard
Click **"← Back to Dashboard"**
- Test card now shows your score
- Click "Review" to see answers again
- Click "Retake" to take the test again

## 🐛 Troubleshooting

### Q: Registration form won't submit
**A**: Check that name and email are filled. Both are required.

### Q: Questions not loading
**A**: Refresh browser. Check browser console (F12) for errors.

### Q: Timer not showing
**A**: Click "Start Test" button to begin—timer appears then.

### Q: Questions look cut off
**A**: Resize browser window. Layout is responsive.

### Q: Can't see answer review
**A**: Check "Results" tab on dashboard, or retake test to see review again.

### Q: Scores disappeared after refresh
**A**: Refresh was tested—should persist. Try registering again if needed.

## 🎓 Sample Answers (for verification)

### Section 1, Q1
**Code**: `x = 10; y = 2; print(x // y, x % y)`
**Expected Output**: `5 0`
**Explanation**: `//` is floor division (10÷2=5), `%` is modulo (10 mod 2=0)

### Section 2, Q1
**Code**: `for i in range(3): print(i)`
**Output**: `0 1 2` (on separate lines)
**Explanation**: `range(3)` gives 0, 1, 2 (not 3)

### Section 3, Q1
**Code**: `s = [1, 2, 3, 4]; print(s[-1] + s[0])`
**Output**: `5`
**Explanation**: `s[-1]` = 4 (last), `s[0]` = 1 (first), sum = 5

### Section 4, Q1
**Code**: `def add(a, b): return a + b; print(add(3, 5))`
**Output**: `8`
**Explanation**: Function returns sum of parameters

### Section 5, Q1
**Code**: `try: 10/0 except ZeroDivisionError: print("caught")`
**Output**: `caught`
**Explanation**: Division by zero is caught by handler

### Section 6, Q1
**Code**: `class Dog: def bark(self): return "woof"; d = Dog(); print(d.bark())`
**Output**: `woof`
**Explanation**: Instance method called on object
